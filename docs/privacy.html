Privacy note

Effective 25 October 2026 Version 1.0.0 com.wichosu.simplerunner

Simple Runner records runs on your phone and sends nothing about them anywhere. There is no account, no server belonging to the project, and no way for anyone — including the person who wrote the app — to see your runs.

What is stored on your phone

For each run the app keeps the data needed to draw it back: start and end time, distance, moving time, pace, and the GPS fixes that survived filtering. For each fix that means latitude, longitude, timestamp, reported accuracy and which part of the run it belongs to.

This lives in the app's private database. It is not readable by other apps, and Android's automatic cloud backup is switched off for Simple Runner, so it is not copied to Google's servers by the operating system. Uninstalling the app, or clearing its storage in Android settings, deletes all of it.

Location

The app asks for precise and approximate location the first time you start a run, and reads location only while a run is recording or paused. It does not ask for background location: there is no “allow all the time” option to grant, and nothing is tracked when a run is not active.

Fixes are processed and stored on the device. They are never uploaded, aggregated or used to build a profile.

The map, and the one network request

Simple Runner has the internet permission for a single purpose: fetching map tiles. Whenever a map is on screen, the area you are looking at is requested from OpenFreeMap, which serves map data from OpenStreetMap contributors. Like any web service, OpenFreeMap and its hosting provider receive your IP address and the coordinates of the tiles requested, from which the approximate map area can be inferred.

No run data is ever included in those requests — not your route, not your speed, not the run's identifier. Recording, history, and the numbers work with no connection at all; only the map needs one.

Notifications

While a run is recording, a notification shows its status and offers pause and finish. It is generated on the device. The notification permission is used for that notification and nothing else.

What is never done

  • No accounts, sign-in, email addresses or profiles.
  • No analytics, telemetry, advertising or crash reporting.
  • No third-party SDKs that collect data. The map renderer, MapLibre, runs locally.
  • No selling, sharing or publishing of anything, because nothing leaves the device.
  • No access to contacts, photos, files, microphone, camera or other apps.

This website

This site is a set of static files. It sets no cookies, runs no scripts, loads no fonts or images from third parties, and has no analytics. The host — currently GitHub Pages — processes standard request logs, including IP addresses, under GitHub's privacy statement.

Children

The app is not directed at children and collects no personal data from anyone, of any age.

Changes

If a future version changes any of this — for example by adding an optional export or sync — this note will be updated before that version ships, and the date at the top will change. The full history is visible in the repository.

Contact

Questions or corrections belong in the issue tracker: github.com/wichosu/simple-runner/issues.
